# GitHub social preview

`Assets/Original/social-preview.svg` is an original 1280×640 design. GitHub’s social-preview uploader may require a PNG; export the SVG at 1280×640 without changing its aspect ratio.

Repository admin steps:

1. Open **Settings → General → Social preview**.
2. Upload the exported image.
3. Confirm the preview reads “AI MONITOR — All your AI usage in one tiny Mac.”
4. Do not label it a real application screenshot. It is a design preview until replaced by a capture from a signed build.
