PLAIN-LANGUAGE POLICY

Privacy

Last updated: August 18, 2026.

Local by design

AI Monitor stores account labels, preferences, sanitized provider state, and the minimal widget snapshot on your Mac. It has no AI Monitor analytics service, advertising SDK, or hosted account proxy.

Provider connections

Codex communication uses the official local Codex App Server process. Custom MCP endpoints are contacted only after you configure them. Provider authentication data stays under provider control or in macOS Keychain; the widget never receives credentials.

Diagnostics

Diagnostic exports are generated only when you request them. The app masks email addresses, home-directory paths, and secret-like values. Review any export before sharing it.

Network requests

The app may contact a configured provider endpoint or GitHub when you explicitly check for an update. It does not scrape provider websites.

Questions

Open a privacy or security issue through the links in the repository's security policy.
