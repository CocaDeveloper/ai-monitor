Support

Codex is not detected

Install or update Codex, then open Settings → Advanced and verify the detected executable. AI Monitor also checks the Codex bundled inside ChatGPT for Mac.

Login does not complete

Keep AI Monitor running after the browser opens. Retry once, then export sanitized diagnostics from Settings → Advanced. Never paste tokens or raw authentication files into an issue.

The widget is stale

Open AI Monitor and refresh. The widget intentionally reads only the last safe shared snapshot; it does not start provider processes in the background.

Kling is unavailable

This is expected in the initial beta shell. No verified official consumer credit API is currently implemented, and AI Monitor will not scrape the Kling website.

Report a problem

Use the GitHub issue forms. Include app version, macOS version, provider, reproduction steps, and reviewed sanitized logs.
