## Detailed announcement — English

AI subscriptions are hard to track across multiple accounts and services.

AI Monitor puts limits, resets and credits in one tiny retro Mac menu bar popup. The first verified release focuses on Codex / OpenAI, supports isolated multiple accounts, preserves the last valid value when a refresh fails, and includes Small and Medium desktop widgets. It uses the official Codex App Server instead of scraping ChatGPT. Kling remains clearly labeled unavailable until a supported read-only balance interface exists.

The app has no analytics and stores account metadata locally. Source, privacy details, tests, and the signed/notarized DMG are here: [repository].
