# Support

1. Read the FAQ in [README.md](README.md).
2. Check [existing issues](../../issues) for the exact message.
3. Use **Export Diagnostics** and review the file before sharing it.
4. Open the most specific issue form: bug, provider request, or connection problem.

Never share passwords, tokens, API keys, cookies, private keys, full `auth.json`, or URLs containing credentials. This community project cannot provide emergency, billing, or account-recovery support; contact the provider for those matters.
